### What changed since v0.1.24

- Release builds now contain the Standard edition only. Each native platform bundles Concert Grand and the pinned official instruments and effects; Minimal artifacts are no longer produced.
- Plugin pages load more reliably in the browser and Android host. PLAY's plugin picker waits for its list, and on-demand CONFIG opens only for plugins that declare a configuration surface.
- The Rack instrument program selector avoids redundant host updates and preserves its list position across catalog refreshes. Rack saving and the editor header are steadier: an empty Rack name no longer starts an invalid preview, and the name field has more room.
- LIVE's Song and Song Part editor has updated controls and more dependable creation and editing flows.
- The Controllers selector shows every installed supported model, with connected devices first and the rest available to inspect before connection.

### Notes

- The standalone browser host currently exposes only the KeyLab controller package. The full controller catalog is bundled with Android, Desktop and Raspberry Pi.
- An Android APK signed by CI may not install over a differently signed preview. Export important presets and Racks before removing an earlier preview.
