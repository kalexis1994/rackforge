# RackForge for Android

The Android ARM64 preview includes the Standard instruments and effects.
Download the APK, allow your browser or file manager to install it, and open
RackForge. [RackForge-Android-arm64.apk](https://github.com/kalexis1994/rackforge/releases/latest/download/RackForge-Android-arm64.apk)

## Play your first sound

1. Open **PLAY** and choose an instrument and program.
2. Play the on-screen **Touch Controller** or enable your MIDI controller in
   **Audio & MIDI**.
3. Use **Audio & MIDI** to choose the built-in speaker or a USB audio interface.
   A powered USB hub can connect a controller and an interface together.

RackForge reports the active stream and its buffer settings in **Audio & MIDI**.
Try the available audio modes if you hear dropouts. RackForge keeps audio
active while the screen is locked and releases held notes when a MIDI input
disconnects.

Use **Plugin Manager** to install additional `.rfplugin` packages. For the
included instruments and effects, see the current release notes.
[Latest release](https://github.com/kalexis1994/rackforge/releases/latest)
