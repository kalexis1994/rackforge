### What changed since v0.1.32

- Standard builds now bundle Concert Grand 0.171.37, with the physical string-coupling, tension and subtle unison improvements evaluated in the full Nocturne and La Campanella renders.
- Concert Grand now has its own [public repository](https://github.com/kalexis1994/rackforge-plugin-concert-grand). It remains included as RackForge's default instrument. Every platform consumes the same versioned release package, verified by SHA-256, instead of rebuilding a separate copy inside the host.
- The Concert Grand package includes its attested ARM64 native renderer for Raspberry Pi. The accepted model was verified against the portable renderer, and complete musical renders from the Raspberry matched the Windows reference sample for sample.
- Host integration checks continue to exercise the released Concert Grand package through the sequential and parallel rendering paths. Instrument development, its acoustic tests and laboratory reports now live in the independent repository.
